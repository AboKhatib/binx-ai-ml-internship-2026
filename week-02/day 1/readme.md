# Day 1 – week 2 Descriptive Statistics

## Overview

The first day of Week 2 introduced descriptive statistics, providing the mathematical foundation for understanding and summarizing datasets before applying machine learning models.

## Topics Covered

- Mean
- Median
- Mode
- Range
- Variance
- Standard Deviation
- Interquartile Range (IQR)
- Percentiles
- Quartiles
- Effect of outliers

## Practical Work

Completed exercises involving:

- Calculating measures of central tendency
- Measuring data dispersion
- Comparing mean and median on skewed datasets
- Computing statistical summaries using NumPy and Pandas
- Documenting statistical findings in Markdown

## Technologies

- Python
- NumPy
- Pandas
- Jupyter Notebook

## Learning Outcomes

After completing Day 1 I can:

- Summarize numerical datasets using descriptive statistics.
- Interpret measures of center and spread.
- Recognize the influence of outliers on statistical measures.
- Select appropriate statistics for different types of data.
