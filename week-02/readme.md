# Week 2 – Mathematical Foundations & Exploratory Data Analysis

## Overview

Week 2 built the mathematical and analytical foundation required for machine learning. The focus was on descriptive statistics, probability, linear algebra, and exploratory data analysis (EDA), enabling a deeper understanding of data before model development.

Throughout the week, theoretical concepts were immediately reinforced through practical exercises using Python and common data science libraries.

---

## Learning Objectives

- Understand descriptive statistics and data distributions.
- Apply probability concepts to real-world problems.
- Learn the linear algebra concepts used in machine learning.
- Perform exploratory data analysis on real datasets.
- Detect outliers and identify relationships between variables.
- Communicate insights through effective visualizations and data storytelling.
