# Day 2 – Linear Regression

## Overview

Day 2 of Week 3 focused on building the first supervised machine learning model using **Linear Regression**. The session introduced the concept of predicting continuous numerical values, training a regression model with Scikit-learn, interpreting model parameters, and evaluating model performance using standard regression metrics.

## Topics Covered

- Linear Regression Fundamentals
- Continuous Value Prediction
- Training a Linear Regression Model
- Model Coefficients and Intercept
- Regression Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Coefficient of Determination (R²)
- Baseline Model Comparison

## Practical Work

Completed hands-on exercises to:

- Load and prepare a regression dataset.
- Train a `LinearRegression` model using Scikit-learn.
- Generate predictions on unseen test data.
- Examine the model's coefficients and intercept.
- Evaluate model performance using MAE, RMSE, and R².
- Compare the trained model against a simple baseline.
- Document the workflow and interpret the results using Markdown cells.

## Technologies

- Python
- Pandas
- Scikit-learn
- NumPy
- Jupyter Notebook

## Learning Outcomes

After completing Day 2 I can:

- Explain how Linear Regression models predict continuous values.
- Train and use a Linear Regression model with Scikit-learn.
- Interpret model coefficients and the intercept.
- Evaluate regression models using MAE, RMSE, and R².
- Compare model performance with a baseline to determine its effectiveness.
- Apply the standard Scikit-learn workflow for regression tasks.
