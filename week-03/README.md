# Week 3 – Supervised Machine Learning with Scikit-learn

## Overview

Week 3 marks the transition from mathematical foundations to practical machine learning. Throughout this week, the focus shifted to **Supervised Learning**, where real machine learning models were built, trained, and evaluated using the Scikit-learn library.

The week introduced the complete supervised learning workflow, including data preparation, model training, prediction, performance evaluation, and model comparison. By working with real datasets, I gained hands-on experience implementing both regression and classification algorithms while following industry-standard machine learning practices.

---

## Learning Objectives

- Understand the fundamentals of supervised machine learning.
- Distinguish between regression and classification tasks.
- Prepare datasets for machine learning using features and target variables.
- Train and evaluate regression and classification models.
- Interpret model outputs and performance metrics.
- Compare multiple machine learning algorithms.
- Build a complete end-to-end supervised learning workflow.
