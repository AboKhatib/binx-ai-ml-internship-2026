# Day 1 – Introduction to Supervised Learning & the Scikit-learn API

## Overview

The first day of Week 3 introduced the fundamentals of supervised machine learning. The session focused on understanding how supervised learning works, distinguishing between regression and classification problems, organizing datasets into features and target variables, and using the Scikit-learn API to build a standard machine learning workflow.

## Topics Covered

- Introduction to Supervised Learning
- Regression vs. Classification
- Features (X) and Target (y)
- The Scikit-learn API
- Train/Test Split
- Model Training Workflow
- Reproducible Machine Learning Experiments

## Practical Work

Completed hands-on exercises to:

- Load a dataset into a Pandas DataFrame.
- Separate the dataset into features (`X`) and target (`y`).
- Perform an 80/20 train-test split using Scikit-learn.
- Verify the dimensions of the training and testing datasets.
- Understand the importance of evaluating models on unseen data.
- Document the machine learning workflow using Markdown cells.

## Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Learning Outcomes

After completing Day 1 I can:

- Explain the concept of supervised learning.
- Differentiate between regression and classification tasks.
- Prepare datasets for machine learning by separating features and target variables.
- Use Scikit-learn's consistent API to structure machine learning workflows.
- Split datasets into training and testing sets following best practices.
- Understand why evaluating models on unseen data is essential for reliable performance estimation.
